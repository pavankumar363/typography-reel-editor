# Typography Reel Editor — Free Edition

A browser-based kinetic typography editor inspired by the public free workflow shown in TypographyEdit screenshots. This is an independent implementation, not the original site's source code.

## Features
- Script to scenes
- Free style gallery with 16 editable presets
- Scene list and timeline
- 9:16, 16:9 and 4:3 canvas presets
- Per-scene background/text/key/ghost colors
- Separate text, key-word and background fonts
- Watermark toggle/visibility, soft glow, motion, speed, duration and text size
- Edit Words panel and emphasized word
- Audio file selection (currently loads/selects file; audio is not mixed into rendered export)
- SRT caption download
- Browser canvas video export (MP4 only when supported, otherwise WebM)
- Local browser persistence

## Run / publish
This is a static website. Enable GitHub Pages for the main branch, root folder. No build step is required.

## Limitations
No AI speech recognition, automatic word-level audio synchronization, cloud accounts, multi-device project sync or premium-template bypass. This project does not copy proprietary server code or paid features from TypographyEdit.
